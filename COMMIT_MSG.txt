修复"中途建邦没有颜色 → 白色旗标 → 崩游戏"的真正根因

== 根因 ==

1) DLL 侧取 PlayerConfiguration 取错了（"一调就卡死"的原因）
   旧代码 cfg = FUN_1802209a0(FUN_1807d0780(), slot) ——
   FUN_1807d0780() 是文明表，FUN_1802209a0 的第二个参数是文明索引
   （FUN_180228580 传的是 FUN_180169ee0(cfg)），不是玩家槽位。
   拿槽位索引文明表 → 越界垃圾指针 → setter 尾跳 [垃圾+0x130] → 卡死。
   引擎自己的取法（FUN_180617370 / FUN_180616d30 / FUN_1806185f0 /
   FUN_1806172d0 / FUN_180619a00 五处一致）：
       mgr  = FUN_180164c20()             // return DAT_180b8aa78;
       base = *(void**)(mgr + 0x90)
       cfg  = (char*)base + slot * 0x20   // 步长 0x20
   C6FW 已按此重写（commit 618ab95）。

2) UI 那张「玩家 → 颜色」表开局后永不刷新（"白色旗标"的原因）
   UI.GetPlayerColors(playerID) 读 UI 自己的表，开局建好后不再更新，
   中途激活的槽不在表里 → 返回 nil → SetColor(nil) → 原生读 NULL+0xc → 崩。
   实测：UI.GetPlayerColors(6)= -15198184（真城邦），(34)= nil（我们）；
        UI.GetPlayerColorValues("CIVILIZATION_AKKAD",0) = -15198184。
   UI.GetPlayerColors 只读（覆写报 lReadOnlyError），全游戏 ~70 处调用点。

== 改动 ==

C6FW：lua_bridge.cpp 换正确取法；新增 GetPlayerColorBySlot /
      CopyPlayerColor / ColorTypeIndex；修正 SetPlayerColorBySlot。

MOD：新增 UI/CSF_UICommon.lua（CSF_SafePlayerColors，绝不返回 nil）、
     UI/CSF_UnitFlagManager.lua（单位旗标兜底，LoadOrder 500002）；
     CSF_CityBannerPatch.lua 取色改走公共兜底；
     CSF_CreateCityState.lua 重写补色逻辑、**删掉会卡死的 InitUnit 兜底**；
     CSF_Gameplay.lua 激活成功后立刻补色。

== 实测验收（2026-10-07，全新开一局）==

① 建邦后颜色正常：
   [CSF] 补色成功 slot=34 ← slot 6 颜色=-1992743837
   [CSF] ✅ 城邦槽 34 已完整激活（CIVILIZATION_AKKAD）alive=true status=1
   [CSF] slot-activate: Cities:Create(37,23) player=34 ok=true → 城市数 = 1
   DLL 读数 == Lua 读数 == -1992743837；旗标实渲色 -15198184（与真城邦一致）。
② 全图视野不崩：SetAllRevealed(true, me) 后进程/Tuner/弹窗/事件日志全 OK。
③ 可交互：选城开城市面板、给城邦造单位（旗标渲染）、开城邦总览，全部无崩。
   全程无 "SetColor with nil value"。

== 遗留（非崩溃级）==
UI.GetPlayerColors(我们的槽) 仍为 nil（UI 表不刷新且函数只读）。
已堵住会崩的两条路径（城市旗标、单位旗标）；其余面板取不到色只显示兜底色
或报 Lua 错，实测不致命。彻底解决需在 exe 侧找到给 UI 填色的原生函数
（UI.GetPlayerColors 注册在 CivilizationVI.exe，不在 GameCore DLL）。
