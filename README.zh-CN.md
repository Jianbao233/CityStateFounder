# 城邦缔造者 / City-State Founder

**文明六（Sid Meier's Civilization VI）** 模组 —— 让你亲手决定城邦出现在地图的哪个位置。

[English →](README.md)

---

## 它做什么

新增一个单位：**建邦使节**。它不能建立普通城市，而是在它所在的格子上建立一个**城邦**。

建出来的城邦是**引擎层面的真城邦** —— 颜色、名称、使者、宗主加成、任务全部正常。
它是**独立的**：由 AI 接管，不属于你。

## 怎么用

1. 造一个**建邦使节**（150 生产力，平民单位，陆地）。
2. 把它移动到你想让城邦出现的位置。
3. 打开单位面板，点**建立城邦**。
4. 面板会列出本局可用的每一个城邦 —— 图标、名称、宗主加成。
5. 选一个并确认。该城邦的移民会就位，并在它自己的回合建城。

作为缔造者，你获得 **1 个使者**。

## 能建几个？

列表只显示**你当前这局里真实存在的城邦** —— 因为只有它们能被完整地创建出来。
数量由**你的开局设置**决定：

| 地图大小 | 城邦上限 |
|---|---|
| 决斗 | 最多 6 个 |
| 极小 | 最多 10 个 |
| 小 | 最多 14 个 |
| 标准 | 最多 18 个 |
| 大 | 最多 22 个 |
| 巨大 | 最多 24 个 |

想要更多选择，请在创建游戏时把城邦数量调高。

## 前置要求

- **迭起兴衰** 或 **风云变幻**（模组在风云变幻规则集下加载）。
- 单机可用，未测试联机。

## 安装

把 `src/` 目录复制到你的文明六模组目录，并改名为 `CityStateFounder`：

```
Documents\My Games\Sid Meier's Civilization VI\Mods\CityStateFounder\
```

该目录顶层必须能看到 `CityStateFounder.modinfo`。

## 设计说明（想改这个模组的话值得一看）

- **城邦是在开局预留的。** 在 `LoadScreenClose` 时，所有还没建城的城邦会被送下地图，供玩家之后自行放置。
  所以"可建数量"就等于这局的城邦总数。
- **建邦不调用 `Cities:Create`。** 而是把该城邦的移民放到目标格，让城邦自己的 AI 在它的回合建城。
  直接 `Cities:Create` 可能**静默失败并永久损坏目标城邦**，所以本模组完全避开它。
- **运行时凭空造新城邦玩家是不可行的。** `WorldBuilder.PlayerManager():AddPlayer` 造出的玩家，
  引擎的 UI 层并不完全认识（旗帜没有颜色、外交状态异常）。这一点做过大量实测并已否决 —— 详见源码注释。
